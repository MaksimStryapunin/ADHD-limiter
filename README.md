# ADHD-limiter

Открытое приложение на C++/WinAPI для разграничения времени «работа/отдых» и переключения внимания.

## Что реализовано (beta)

- Оконное приложение Windows (не полноэкранное) со стандартными системными кнопками: свернуть, развернуть/восстановить, закрыть.
- Системный фон окна.
- 3 интерактивных элемента, масштабируемых при изменении окна:
  - левый зелёный числовой бокс (отдых, минуты),
  - правый красный числовой бокс (работа, минуты),
  - нижняя кнопка-стрелка (пуск/подтверждение).
- Символ `+-` отрисовывается между левым и правым боксами.
- Таймеры по умолчанию: работа `20`, отдых `20`.
- После завершения текущего таймера:
  - звучит системное уведомление,
  - кнопка меняется на вариант с «стрелкой с палочкой» для подтверждения перехода,
  - следующий таймер запускается только после нажатия этой кнопки.
- Значения можно изменять при старте и в паузе между таймерами.

## Сборка (Windows)

Требования: CMake 3.20+ и компилятор с поддержкой C++17 (MSVC).

```powershell
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Исполняемый файл:

- `build/Release/ADHD-limiter.exe` (Visual Studio generator)
- или `build/ADHD-limiter.exe` (single-config generator)

## Запуск

1. Откройте `ADHD-limiter.exe`.
2. При необходимости измените минуты в зелёном/красном боксах.
3. Нажмите кнопку `▶` для старта.
4. После звукового сигнала нажмите кнопку подтверждения `⏭|` для переключения на следующий период.

- собирает Windows `.exe`;
- формирует архивы популярных форматов `zip` и `tar.gz` через CPack;
- прикрепляет архивы к GitHub Release.
